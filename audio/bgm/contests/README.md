Contest-specific background music belongs here.

Use keys like `contests/contest_theme` so the existing BGM loader resolves
`assets/audio/bgm/contests/contest_theme.mp3`.


The music which plays when the event appears up to when the contest phases start is
pokemon_contest_lobby.mp3
The main theme which plays during contest stages is
pokemon_contest.mp3
we also have
pokemon_contest_alt_1.mp3
pokemon_contest_alt_2.mp3
pokemon_contest_alt_3.mp3
pokemon_contest_alt_4.mp3
which can be substituted in for variety.

The theme which plays during the End phase is
pokemon_contest_result_announcement.mp3
except if a player has taken first place in which case it will use
pokemon_contest_winner.mp3 instead.
