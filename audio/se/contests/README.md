Contest-specific sound effects belong here.

Load these through the existing sound effect loader with the `se/contests`
folder, then play them with keys like `se/contests/applause`.

Sound effect contest_appeal_heart_change.wav plays when an appeal heart is obtained. pitched up slightly higher for each heart gained.

IE if it gains six hearts it plays
60,60+,60++,60+++,60++++,60+++++

Sound effect contest_turn_notification.wav plays at the start of the command phase. to alert the players that it is someones turn. though this also plays when the AI has its turn starting.

Sound effect contest_cheering.wav plays when the applause meter goes up. though it is quiet and shortened unless the meter has been completely filled.
